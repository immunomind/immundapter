    Assign germline genes to raw receptor sequences with IgBLAST

    Source code

    Description

    IgBLAST identifies the germline genes that most likely produced each immune receptor sequence. It produces V, D, J, and, when available, C gene calls in an AIRR table that can be imported with immundata::read_repertoires().

    The usual workflow is:

    run <- tool_igblast()$run(c(
  fasta = "sequences.fasta",
  annotations = "contig_annotations.csv"
))
idata <- immundata::read_repertoires(
  path = run$results()$final_output,
  schema = immundata::make_receptor_schema(
    features = c("v_call", "j_call", "junction_aa"),
    chains = c("IGH", "IGK|IGL")
  ),
  barcode_col = "barcode",
  locus_col = "locus",
  umi_col = "umis",
  preprocess = immundata::make_default_preprocessing("10x"),
  rename_columns = NULL
)

    Usage

    conf_igblast(num_threads = NULL, run_args = list())

tool_igblast(config = conf_igblast())

    Arguments

    num_threads Number of computer threads available to IgBLAST. NULL uses the IgBLAST default.
    run_args Additional named arguments passed through … in igblastr::igblastn(). This is intended for advanced settings. Arguments required by the immundapter workflow cannot be changed here.
    config Settings created by conf_igblast().

    Details

    IgBLAST compares observed receptor sequences with a germline database. The database selected through igblastr determines the species and receptor type. For example, select a human BCR database before analysing human immunoglobulin sequences.

    Query sequences must be nucleotide sequences without alignment gaps. Supply the complete assembled V(D)J sequence when possible. Amino-acid sequences and sequences that already contain IMGT dots are not valid input. A CDR3 nucleotide sequence alone usually does not contain enough information for useful V- and J-gene annotation.

    Value

    conf_igblast() returns read-only IgBLAST settings. tool_igblast() returns a reusable IgBLAST tool.

    Before the first analysis

    Install IgBLAST and one germline database with igblastr. Select the database in the same R session in which you run the analysis:

    igblastr::install_igblast()
igblastr::install_IMGT_germline_db(
  "<release>",
  organism = "Homo sapiens",
  tcr.db = FALSE
)
igblastr::use_germline_db("<db-name>")

    Use tool$help() for setup commands and tool$check() to confirm that the selected database and IgBLAST installation are ready.

    Run the tool

    tool_igblast() creates a reusable tool. Its main methods are:

    • tool$help(): print installation and database setup instructions;
    • tool$check(): check that IgBLAST and a germline database are ready;
    • tool$run(input, config = NULL, output_dir = NULL): run one analysis.

    The tool keeps its default settings in tool$config. Supplying config to $run() replaces those settings for that run only.

    Choose the input

    tool$run() accepts two forms of input:

    • A FASTA file. Pass a path ending in .fasta or .fasta.gz. Use this when no annotation table needs to be preserved.
    • A FASTA file and its annotation table. Pass c(fasta = “sequences.fasta”, annotations = “annotations.csv”). Use this for data such as 10x contigs when barcodes, UMI counts, and sample columns must remain beside the new IgBLAST annotations.

    Read the results

    tool$run() saves the analysis and returns a completed run object. Its $path is the output directory and $artifacts lists the saved files. Call run$results() to access the biological results. Every run provides:

    • results$airr: the complete AIRR annotation table;
    • results$mapping: the link between input records and AIRR sequence_id;
    • results$raw_output: the path to the saved AIRR TSV file.

    The tables are disk-backed. Use dplyr::collect() only when you want to bring a table into R memory.

    With paired FASTA and annotation input, results$final contains the source columns joined with all AIRR columns. results$final_output is the path to the same table as a TSV file. Pass this file to immundata::read_repertoires() to create an ImmunData dataset. Choose preprocessing that retains sequence_alignment when subsequent analyses need IMGT-gapped alignments and coordinates.

    IMGT gaps and coordinates

    igblastr builds the searchable IgBLAST database from ungapped germline sequences. It also keeps the original IMGT-gapped V references. These two forms have different V-gene coordinates.

    For a selected IMGT database, immundapter automatically uses both forms from the same installed database release. IgBLAST first performs the search against the ungapped database. immundapter then uses the matching gapped V allele to place IMGT dots in sequence_alignment and convert v_germline_start and v_germline_end to the IMGT-gapped coordinate system. This follows the normalization used by Change-O for germline reconstruction.

    Do not download a newer gapped FASTA separately: allele content and gap positions must match the database used by IgBLAST. If the selected IMGT database does not contain its original gapped V FASTA files, reinstall that database with igblastr::install_IMGT_germline_db().

    Normalization uses the first allele in v_call. If the allele or the exact aligned V end cannot be matched to the selected reference, that row keeps the original IgBLAST alignment and coordinates. Non-IMGT databases are also returned in their original IgBLAST coordinate system. D- and J-region coordinates are not converted to IMGT-gapped V coordinates.

    Input details

    FASTA names must be unique. In >cell_1 description, the name is cell_1. For paired input, the annotation table must contain a unique contig_id or sequence_id column whose values match the FASTA names. CSV, TSV, TXT, and gzip-compressed annotation files are accepted.

    Examples

    library("immundapter")


# Select an installed human BCR IMGT database.
databases <- igblastr::list_germline_dbs(names.only = TRUE)
databases <- grep(
  "Homo_sapiens.IGH+IGK+IGL",
  databases,
  value = TRUE,
  fixed = TRUE
)
databases <- grep("^IMGT-", databases, value = TRUE)
stopifnot(length(databases) > 0L)
suppressMessages(
  igblastr::use_germline_db(sort(databases)[[length(databases)]])
)

config <- conf_igblast()
tool <- tool_igblast(config)
stopifnot(tool$check())

antitnf_dir <- system.file("extdata", "antitnf", package = "immundapter")
antitnf_fasta <- file.path(antitnf_dir, "bcr_contigs.fasta.gz")
antitnf_annotations <- file.path(
  antitnf_dir,
  "contig_annotations.csv.gz"
)

# Analyse a FASTA file directly.
fasta_run <- tool$run(
  antitnf_fasta,
  output_dir = tempfile("igblast-fasta-")
)
fasta_airr <- dplyr::collect(fasta_run$results()$airr)

# Preserve the matching 10x annotation table and import the AIRR result.
paired_run <- tool$run(
  c(
    fasta = antitnf_fasta,
    annotations = antitnf_annotations
  ),
  output_dir = tempfile("igblast-10x-")
)
idata <- immundata::read_repertoires(
  path = paired_run$results()$final_output,
  schema = immundata::make_receptor_schema(
    features = c("v_call", "j_call", "junction_aa"),
    chains = c("IGH", "IGK|IGL")
  ),
  barcode_col = "barcode",
  locus_col = "locus",
  umi_col = "umis",
  preprocess = immundata::make_default_preprocessing("10x"),
  rename_columns = NULL,
  output_folder = tempfile("antitnf-immundata-")
)
